Qué son los elementos semánticos:

                DIV: Es un elemento en bloque genérico que sirve como contenedor para agrupar otros elementos y estructurar una página web.
                SPAN: Es un contenedor genérico en línea que sirve para agrupar fragmentos de texto o elementos pequeños y aplicarles estilos o interactividad.
            
                Los elementos header, nav, main, section, article, aside, footer y address sirven para organizar una página web de forma clara.
                Header es la cabecera, nav contiene el menú de navegación, main el contenido principal, section divide el contenido en secciones- 
                Article representa un contenido independiente como una noticia, aside muestra información secundaria, footer es el pie de página. 
                Address contiene información de contacto.
